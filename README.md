Leonida Legend is an offline guide and tracker for all 55 GTA 6 PS5 trophies: official names, descriptions and grades, own-words guides with cited sources, a platinum roadmap and missable flags, plus a saved checklist with export/import, filters and a spoiler mode.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser (`node serve.ts --port <n>` for another port).
